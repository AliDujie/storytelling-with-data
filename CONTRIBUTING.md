# Contributing Guide / 贡献指南

Thank you for your interest in contributing! / 感谢你对本技能的兴趣和贡献！

## How to Contribute / 如何贡献

### 1. Report Bugs / 报告 Bug

- Check existing issues first / 先检查是否已有类似 issue
- Include Python version, OS, and steps to reproduce / 包含 Python 版本、操作系统和复现步骤
- Add code snippets if applicable / 如果适用，附上代码片段

### 2. Suggest Features / 建议新功能

- Describe the use case / 描述使用场景
- Explain the expected behavior / 说明预期行为
- Provide examples if possible / 如有可能，提供示例

### 3. Submit Code / 提交代码

1. Fork the repository / Fork 仓库
2. Create a feature branch (`git checkout -b feature/amazing-feature`) / 创建功能分支
3. Make your changes / 进行修改
4. Test thoroughly / 充分测试
5. Commit with clear messages / 使用清晰的提交信息
6. Push to your branch / 推送到你的分支
7. Open a Pull Request / 发起 Pull Request

## Code Style / 代码规范

- Follow PEP 8 guidelines / 遵循 PEP 8 规范
- Use type hints where appropriate / 适当使用类型标注
- Add docstrings to public functions / 为公共函数添加文档字符串
- Write tests for new features / 为新功能编写测试

## Pull Request Guidelines / PR 指南

- Keep PRs focused and small / 保持 PR 聚焦且精简
- Include tests for new features / 为新功能包含测试
- Update documentation if needed / 必要时更新文档
- Ensure all tests pass / 确保所有测试通过

## Documentation / 文档贡献

- Improve bilingual (CN/EN) support / 完善中英双语支持
- Add real-world usage examples / 添加真实使用示例
- Update references when source material changes / 当源材料变更时更新参考文档
