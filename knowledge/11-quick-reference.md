# 速查手册 (Quick Reference)

## SWD六课速查

| 课程 | 核心问题 | 关键行动 |
|------|---------|---------|
| 1.上下文 | 受众是谁？需要他们做什么？ | Who-What-How→Big Idea→故事板 |
| 2.图表选择 | 什么图表最容易被受众理解？ | 决策树选图→避免饼图/3D/双Y轴 |
| 3.去杂乱 | 哪些元素不增加信息价值？ | 六步去杂乱→格式塔原则 |
| 4.注意力 | 受众应该先看什么？ | 灰色基底+强调色→视觉层次 |
| 5.设计师 | 是否专业且易理解？ | 可供性+可访问性+美学 |
| 6.故事 | 数据讲了什么故事？ | 三幕结构→行动标题→BBB |

## 图表选择决策树

```
你要展示什么？
├── 1-2个数字 → 简单文本
├── 精确数值查找 → 表格/热力图
├── 两变量关系 → 散点图
├── 时间趋势
│   ├── 两个时间点 → 坡度图
│   └── 多时间点 → 折线图
├── 分类数据
│   ├── 类别名长/类别>5 → 水平柱状图
│   ├── 类别名短 → 垂直柱状图
│   └── 起点+增减+终点 → 瀑布图
├── 部分与整体 → 100%堆叠水平柱状图
└── 永远避免 → 饼图/甜甜圈/3D/双Y轴
```

## 去杂乱检查清单

- [ ] 移除图表边框
- [ ] 移除或弱化网格线（浅灰细线）
- [ ] 移除不必要的数据标记
- [ ] 去掉尾部零（250.00→250）
- [ ] 消除对角文本（缩写标签）
- [ ] 直接标注数据（不用独立图例）
- [ ] 移除3D效果
- [ ] 移除背景阴影
- [ ] 左对齐（不居中）

## 颜色策略速查

| 策略 | 适用场景 | 做法 |
|------|---------|------|
| 灰色+单色 | 大多数场景（推荐） | 灰色基底+蓝色强调 |
| 单色渐变 | 热力图/排名 | 浅蓝→深蓝 |
| 双色分歧 | 正负对比 | 蓝色(正)+橙色(负) |
| 有限分类 | 多系列区分 | 最多4-5种颜色 |

**颜色五原则**：稀疏使用、一致使用、色盲友好、注意语气、考虑品牌

## 前注意属性速查

**最常用**：颜色(色相)、大小、粗细(线宽)、添加标记、空间位置
**叠加使用**：重要元素同时用颜色+大小+粗体（多个属性叠加效果更强）
**关键规则**：稀疏使用→突出越多效果越弱

## 设计三维度检查

### 可供性
- [ ] 重要内容被突出（最多10%）
- [ ] 干扰元素已消除
- [ ] 清晰的视觉层次

### 可访问性
- [ ] 有图表标题（行动标题优先）
- [ ] 有轴标题
- [ ] 关键数据点有注释
- [ ] 语言简单易懂

### 美学
- [ ] 颜色有策略
- [ ] 元素对齐创建干净线条
- [ ] 白色空间恰当保留

## 故事结构速查

**三幕**：开始(设定+冲突) → 中间(证据+方案) → 结尾(行动号召)
**BBB**：Bing(预告) → Bang(主体) → Bongo(回顾)
**水平逻辑**：只读标题序列应能讲完整故事
**行动标题**：告诉受众"所以呢"而非"这是什么"

## 常见问题→修复映射

| 问题 | 修复 | 原理 |
|------|------|------|
| 饼图 | 水平柱状图 | 人眼难比较角度 |
| 3D | 2D版本 | 扭曲数值 |
| 双Y轴 | 拆分/直接标注 | 难判断对应关系 |
| 无标题 | 添加行动标题 | 受众需知看什么 |
| 彩虹色 | 灰色+单色 | 太多颜色失去价值 |
| 图例 | 直接标注 | 减少认知负荷 |
| 对角文本 | 缩写标签 | 阅读慢52% |
| 居中对齐 | 左对齐 | 不产生干净线条 |
| 意面图 | 逐一强调/空间分离 | 无法聚焦单条线 |

## 五维度诊断评分

每维度20分，总分100分：
1. **上下文**(20)：受众明确？行动号召清晰？Big Idea可识别？数据支撑故事？
2. **视觉选择**(20)：图表类型合适？避免问题图表？零基线？排序有逻辑？
3. **杂乱**(20)：无多余元素？无对角文本？白空间恰当？无冗余？
4. **注意力**(20)：前注意属性？颜色稀疏？视觉层次？眼睛测试通过？
5. **设计叙事**(20)：文本充分？对齐美学？叙事结构？行动标题？

**评级**：90+🟢卓越 | 70-89🟡良好 | 50-69🟠需改进 | <50🔴需重做
