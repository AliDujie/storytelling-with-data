# SWD Runnable Examples / 可运行示例

These examples demonstrate Storytelling with Data capabilities with real-world scenarios.
这些示例用真实场景演示数据叙事能力。

## Quick Start / 快速开始

```bash
cd examples/
python 01_chart_selection.py
```

All examples use **zero dependencies** — pure Python standard library only.
所有示例使用**零依赖** — 仅 Python 标准库。

## Available Examples / 可用示例

### 01_chart_selection.py
Chart type recommendation based on data characteristics.
根据数据特征推荐图表类型。

**Use when / 适用场景**: Deciding which chart to use for your data story.

```bash
python 01_chart_selection.py
```

### 02_story_building.py
Build a three-act data narrative with clear call-to-action.
构建三幕数据叙事并明确行动号召。

**Use when / 适用场景**: Preparing executive presentations or quarterly reports.

```bash
python 02_story_building.py
```

## Tips / 提示

- All examples use relative imports — just run from the `examples/` directory
- No `pip install` required — SWD is zero-dependency
- Feed QuantUX metrics into SWD for data-driven storytelling
- See [USAGE.md](../USAGE.md) for detailed API documentation
