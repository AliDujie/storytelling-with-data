# 第9章：案例研究 (Case Studies)

## 核心概念

本章通过5个真实案例，展示SWD方法论在不同场景中的应用。

## 案例1：深色背景的考量

### 场景
在大型会议/舞台演示中使用深色背景。

### 关键要点
- 深色背景在大屏幕/舞台上效果好（减少眩光）
- 浅色文字在深色背景上需要更大字号
- 颜色选择需要调整——在深色背景上的对比度不同
- 避免纯白文字（太刺眼），使用浅灰色
- 测试：在实际投影环境中检查可读性

## 案例2：动画的策略性使用

### 场景
用动画逐步揭示复杂数据故事。

### 关键要点
- 动画 = 渐进式揭示的技术实现
- 每次只添加一个新元素，配合口头解释
- 避免花哨的过渡效果——简单的"出现"最好
- 动画帮助控制受众的注意力节奏
- 书面版本不能用动画——需要用注释和颜色替代

## 案例3：排序的逻辑

### 场景
用户满意度调查数据的展示（15个功能的满意度分布）。

### 关键要点
- **数据排序必须有逻辑**：自然顺序（如年龄段）或按数值排序
- 100%堆叠水平柱状图适合Likert量表数据
- 在现场演示中逐步强调不同发现：
  1. 先展示整体（全灰）
  2. 强调满意度最高的功能（深蓝色）
  3. 强调满意度最低的功能（橙色）
  4. 强调未使用率最高的功能（青色）
- 书面版本：压缩为一张综合视觉，用多种颜色+注释框

### 排序原则
- 有内在顺序的数据（如年龄段）→ 保持自然顺序
- 无内在顺序的数据（如功能名）→ 按数值排序
- 用颜色和位置引导注意力到重要数据

## 案例4：避免意面图的策略

### 场景
5条重叠的折线图（非营利组织资助类型趋势）。

### 三种策略

**策略1：逐一强调**
- 保留所有线条，但只用颜色强调一条
- 其他线条推到灰色背景
- 适合现场演示——每张幻灯片强调一条线

**策略2：空间分离（垂直）**
- 将5条线拆分为5个小图，垂直排列
- 共享X轴（年份在顶部）
- 类似Tufte的"sparklines"
- 适合看单个类别的趋势

**策略3：空间分离（水平）**
- 将5条线拆分为5个小图，水平排列
- 共享Y轴（百分比）
- 适合跨类别比较

**组合策略**：空间分离 + 逐一强调
- 分离后仍保留其他线条作为灰色参考
- 最灵活的方法

## 案例5：饼图的替代方案

### 场景
将饼图改造为更有效的可视化。

### 关键要点
- 饼图 → 水平柱状图（按大小排序）
- 水平柱状图的优势：
  - 一致的基线便于比较
  - 类别名从左到右书写易读
  - 可以排序突出最大/最小值
- 如果需要展示"部分与整体"→ 100%堆叠水平柱状图

## 跨案例的共同模式

1. **先全灰，再加色** — 所有案例都从灰色基底开始
2. **行动标题** — 每个案例的标题都告诉受众"所以呢"
3. **注释框** — 用文字解释为什么某个数据点重要
4. **数据排序有逻辑** — 自然顺序或数值顺序
5. **现场 vs 书面区分** — 同样的数据，不同的呈现策略
