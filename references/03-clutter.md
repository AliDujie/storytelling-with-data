# 第3章：杂乱是你的敌人 (Clutter Is Your Enemy!)

## 核心概念

空白页面上的**每一个元素**都会占用受众的认知负荷。因此，我们必须审视每个视觉元素，移除任何不增加信息价值（或增加的价值不足以弥补其存在）的东西。

## 认知负荷 (Cognitive Load)

- 认知负荷 = 学习新信息所需的脑力
- 人类大脑的处理能力是**有限的**
- **外在认知负荷**（extraneous cognitive load）= 不帮助理解信息的处理——这是我们要避免的
- **关键**：最重要的是受众**感知到的**认知负荷——他们觉得理解你的信息需要多少努力

### 信号与噪音
- Edward Tufte的"数据墨水比"：图表中用于数据的墨水比例越高越好
- Nancy Duarte的"信号噪音比"：信号=要传达的信息，噪音=不增加或有损信息的元素

## 格式塔视觉感知原则 (Gestalt Principles)

20世纪初格式塔心理学派研究人们如何感知视觉秩序的原则，至今仍被接受。

### 1. 邻近性 (Proximity)
- 物理上靠近的对象被视为**属于同一组**
- **应用**：通过调整间距引导阅读方向（列间距大→读行，行间距大→读列）
- **实践**：不需要边框来分组，间距就够了

### 2. 相似性 (Similarity)
- 相同颜色/形状/大小/方向的对象被视为**相关**
- **应用**：用颜色替代边框来引导阅读方向
- **实践**：交替行颜色可以引导眼睛横向阅读

### 3. 封闭性 (Enclosure)
- 被围起来的对象被视为**属于同一组**
- 不需要很强的围合——轻微的背景阴影就够了
- **应用**：区分实际数据和预测数据（用浅色背景）

### 4. 闭合性 (Closure)
- 人们倾向于将不完整的元素感知为**完整形状**
- **应用**：可以移除图表边框和背景阴影——图表仍然显得完整
- **好处**：去掉不必要元素后，数据更突出

### 5. 连续性 (Continuity)
- 眼睛寻找**最平滑的路径**
- **应用**：可以移除Y轴线——白色空间已经暗示了对齐
- 柱状图的条形即使没有Y轴线也会被感知为对齐的

### 6. 连接性 (Connection)
- 物理连接的对象被视为**一组**
- 连接性通常比相似的颜色/大小/形状有更强的关联力
- **应用**：折线图中的线条帮助看到数据的顺序

## 常见杂乱元素及处理

### 图表边框 → 移除
利用闭合性原则，图表不需要边框仍显完整。

### 网格线 → 移除或弱化
- 如需保留：使用**浅灰色细线**
- 不要让网格线与数据竞争视觉注意力

### 数据标记 → 除非有目的否则移除
折线图中的线条本身已经表达了数据，数据标记是多余的。

### 尾部零 → 去掉
`250.00` → `250`，减少不必要的复杂感。

### 对角文本 → 消除
- 对角文本阅读速度**慢52%**
- 解决方法：缩写标签、使用水平柱状图、增加图表宽度

### 独立图例 → 改为直接标注
- 图例迫使受众在图例和数据之间**来回查看**
- 直接在数据旁边标注系列名称（利用邻近性原则）

### 背景阴影 → 移除
分散注意力，不增加信息价值。

### 居中对齐 → 改为左对齐
- 居中对齐**不产生干净的线条**
- 左对齐创建一条干净的垂直线，引导阅读

## 视觉秩序 (Visual Order)

### 对齐 (Alignment)
- 元素对齐创建**干净的垂直和水平线条**
- 给人统一和内聚的感觉
- 标题左对齐（不要居中）
- Y轴标题与最上面的标签对齐
- X轴标题与最左边的标签对齐

### 白色空间 (White Space)
- 白色空间 = 页面上没有被占用的部分
- **不要**为了填满空间而拉伸图表或添加元素
- 白色空间是**战略性的**——它给元素呼吸的空间
- 保留边距
- 适当的白色空间让设计感觉专业和有意的

### 对比 (Contrast)
- 用对比来区分重要和不重要的元素
- 标题应该比正文更突出
- 数据应该比轴线更突出

## 去杂乱六步骤

1. **移除图表边框** — 利用闭合性原则
2. **移除或弱化网格线** — 如需保留则用浅灰色细线
3. **移除不必要的数据标记** — 除非有目的
4. **清理轴标签** — 去掉尾部零、缩写月份、消除对角文本
5. **直接标注数据** — 消除图例来回查看的工作
6. **使用一致颜色** — 标签颜色与数据颜色匹配

## 实践要点

- 当设计做得好时，它**退入背景**——受众甚至不会注意到
- 当设计做得不好时，受众**感受到负担**
- 杂乱让事物看起来比实际更复杂
- 当视觉感觉复杂时，受众可能决定不花时间理解——你就失去了沟通的机会
